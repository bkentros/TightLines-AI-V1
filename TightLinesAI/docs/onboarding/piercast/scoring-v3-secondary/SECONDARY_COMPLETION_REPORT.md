- Current Michigan DNR port roadmaps and dated reports corroborate season and targetability. Port guidance does not create a pier catch rate.
- Wisconsin yellow-perch timing uses the pooled statewide pier table only for broad shape; Racine/Kenosha strength is capped by local DNR reports.
- The Wisconsin Lake Michigan yellow-perch closure is a hard unavailable gate, not a score penalty.
- Generic offshore, inland, boat-only, stocking-only, and single-occurrence evidence cannot create a numeric pier score.
- Temperature remains a bounded secondary modifier. The broad curves are directional hypotheses and cannot create a season or exceed the fishery-strength ceiling.
