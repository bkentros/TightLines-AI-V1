# Five-city onboarding Pass 2

Private Formula v3 evidence and scoring package for Two Rivers, Kewaunee, Algoma, Manitowoc, and Waukegan. Start with [PASS2_REPORT.md](PASS2_REPORT.md), then review the mandatory [cross-city calibration standard](CALIBRATION_STANDARD.md) and generated `calibration-comparison.csv`.

Regenerate and validate from the `TightLinesAI` directory:

```sh
node docs/onboarding/piercast/five-city-2026-09-pass2/generate-audit.mjs
```

All outputs are research-only. Nothing in this directory makes a city or score public.
