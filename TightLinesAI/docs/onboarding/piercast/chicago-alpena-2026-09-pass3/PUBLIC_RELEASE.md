# PierCast public release

On September 19, 2026, the complete 22-city PierCast catalog was approved for public research access.

The final promotion added these six cities to the public catalog:

- Waukegan, Illinois
- Chicago, Illinois
- Michigan City, Indiana
- Muskegon, Michigan
- Whitehall, Michigan
- Alpena, Michigan

The submitted mobile client reads this catalog from the PierCast backend, so this promotion does not require another mobile build. Public catalog and report access remain subject to the app's existing free-report quota and subscription rules.

Bear Creek and the Rogue River are separate River Run locations and are also available through the public River Run catalog.
