## 0. Candidate capability audit

The prior decision treated a current spring egg-take and a general destination
listing as insufficient for fall timing, but it did not check the DNR technical
report archive. Technical Report 91-1 records Steelhead at the lower weir from
September 3 through November 30, calls the run strong throughout fall, and
places the peak in the week of October 17. Its 1980-90 table also demonstrates
recurring fall returns. Current DNR material separately confirms the Platte's
substantial Steelhead population.
