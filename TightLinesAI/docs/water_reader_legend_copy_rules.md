# Water Reader Legend Copy Rules

Purpose: keep Water Reader legend guidance useful, plain, and shape-safe while preserving the deterministic geometry engine.

## Core Promise

Each legend row should help the angler answer three questions:

- Where should I start on this highlighted structure?
- What should I check next?
- What tells me to slow down, shift, or leave?

The copy can sound intelligent, but it should read like fishing guidance, not internal geometry QA.

## Shape-Safe Coves

Do not assume every cove has a literal mouth, entrance, throat, or back. The detector can mark a classic narrow cove, a broad corner pocket, or a protected shoreline area that behaves like a cove but does not have a clean entrance.

Prefer:

- side closest to open water
- protected side
- inside edge
- outer edge
- shaped bank
- corner pocket
- calmer water
- first clear edge

Avoid generic use of:

- mouth
- entrance
- throat
- back
- far back

Those words are allowed only when a placement kind or semantic anchor truly supports them.

## Guidance Vocabulary

Preferred plain-English translations:

- protected side -> calmer tucked-away side, protected side
- opening-facing side -> side closest to open water, outer edge
- broad-water side -> open-water side
- shoulder -> edge
- stable-looking water -> deeper or calmer water that changes less
- comfort -> shade, wind, cover, or nearby open water
- reference -> starting point, check, edge
- compare -> check both, start with, use this to decide

## Cadence Variety

When a legend has several rows of the same feature class, their bodies should not all use the same rhythm. Rotate through these cadences:

- Start on X, then check Y.
- Use this as a quick checkpoint.
- Treat this as a protected or open-water option.
- Check X first, then leave quickly unless Y is present.
- Make one pass along X, then shift only if the clues line up.

The goal is not to make the app sound random. The goal is to make repeated coves, points, islands, or confluences feel intentionally written. Runtime cadence can rotate from a stable map-specific offset so one lake's five coves do not always start with the same cadence as another lake's five coves.

## Structure Clues

Shade, cover, bait, wind, calmer water, sharper shoreline turns, and quick access to open water are useful clues. If those clues align with the highlighted structure, the row should say that the area deserves more attention.

Good pattern:

> Start on the side closest to open water, then check the calmer inside edge. Stay longer if bait, cover, shade, or a sharper shoreline turn lines up with the highlighted water.

## Safety Boundaries

Keep these guardrails:

- Do not promise fish are present.
- Do not use exact depths unless the feature has real bathymetry.
- Do not imply GPS precision.
- Do not say the whole structure is equally valuable.
- Do not make the row depend on sonar or electronics.
